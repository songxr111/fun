# 平衡子数组计数 - 题解

## 问题分析
我们需要统计给定序列中所有满足以下条件的连续子数组：
1. 所有前缀和都是非负的
2. 整个子数组的和恰好为0

## 关键思路

### 前缀和转换
首先计算前缀和数组 `S`，其中：
- `S[0] = 0`
- `S[i] = S[i-1] + A[i-1]`（对于 i 从 1 到 N）

子数组 `A[i..j]` 的和为 `S[j+1] - S[i]`。

### 条件转换
平衡子数组需要满足：
1. 总和为0：`S[j+1] = S[i]`
2. 所有前缀和非负：对于所有 `k ∈ [i, j]`，`S[k+1] - S[i] ≥ 0`

第二个条件等价于：在区间 `[i, j+1]` 内，`S[i]` 是最小值。

### 算法步骤
1. 计算前缀和数组
2. 使用单调栈找到每个位置右边第一个比它小的位置
3. 按前缀和值分组存储索引
4. 对于每个起点，在限制范围内统计满足条件的终点

## 算法复杂度分析
- **时间复杂度**：$O(N \log N)$
  - 前缀和计算：$O(N)$
  - 单调栈处理：$O(N)$
  - 二分查找：每个索引最多被查找一次，每次 $O(\log N)$
- **空间复杂度**：$O(N)$

## 总结
本题的关键在于将问题转换为前缀和问题，并利用单调栈和二分查找高效统计满足条件的子数组。算法在 $O(N \log N)$ 时间内解决了问题，适用于大规模数据。
