## 题目名称：平衡子数组计数

### 问题描述
定义一个序列为“平衡序列”，如果该序列的所有前缀和都是非负的，并且整个序列的总和恰好为 $0$。  

给定一个长度为 $N$ 的整数序列 $A$，求 $A$ 的连续子数组（即连续子序列）中，是平衡序列的个数。

### 输入格式
- 第一行包含一个整数 $N$ ($1 \leq N \leq 10^6$)，表示序列的长度。
- 第二行包含 $N$ 个整数 $A_1, A_2, \dots, A_N$ ($-10^9 \leq A_i \leq 10^9$)，表示序列 $A$ 的元素。

### 输出格式
- 输出一个整数，表示平衡子数组的个数。

### 样例输入
```plain
6
1 -1 1 -1 1 -1
```

### 样例输出
```plain
6
```

### 样例解释
在样例中，序列为 $[1, -1, 1, -1, 1, -1]$。  

平衡子数组有：

- 子数组 $[1, -1]$（前缀和依次为 $1, 0$，非负且总和为 $0$ ）。共出现了 $3$ 次。
- 子数组 $[1, -1, 1, -1]$（前缀和依次为 $1,0,1,0$，非负且总和为 $0$）。共出现了 $2$ 次。
- 子数组 $[1, -1, 1, -1, 1, -1]$（前缀和依次为 $1,0,1,0,1,0$，非负且总和为 $0$）。 共出现了 $1$ 次。

因此输出 $6$。
